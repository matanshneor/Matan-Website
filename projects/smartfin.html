SmartFin — Household FinanceSmartFin — ניהול תקציב משפחתי

A web app for tracking household income, expenses and savings together. Photograph a receipt and the OpenAI API turns it into a categorized transaction; dashboards show where the money went.

אפליקציית ווב למעקב משותף אחרי הכנסות, הוצאות וחיסכון של משק הבית. מצלמים קבלה וה-OpenAI API הופך אותה לתנועה מסווגת; דשבורדים מראים לאן הלך הכסף.

The challengeהאתגרBudgets fail at data entryתקציב נופל בהקלדת הנתונים

Most household budgets live in a spreadsheet that stops being updated after a few weeks. The analysis is easy; getting the data in is the hard part, especially when two people share the spending.

רוב התקציבים המשפחתיים חיים בגיליון שמפסיקים לעדכן אחרי כמה שבועות. הניתוח הוא החלק הקל; החלק הקשה הוא להכניס את הנתונים, במיוחד כששני אנשים מוציאים מאותו חשבון.

I designed SmartFin so that adding a transaction takes seconds: snap a receipt, import a credit-card statement, or let recurring payments create themselves.

תכננתי את SmartFin כך שהוספת תנועה תיקח שניות: מצלמים קבלה, מייבאים דף אשראי, או נותנים לתשלומים קבועים להיווצר לבד.

What I builtמה בניתיLess typing, clearer numbersפחות הקלדה, מספרים ברורים יותר

AI receipt scanningסריקת קבלות ב-AI

The OpenAI vision API extracts amount, merchant, date and category from a photo, with monthly usage limits per family.

ה-OpenAI Vision API מחלץ מתמונה סכום, בית עסק, תאריך וקטגוריה, עם מגבלת שימוש חודשית לכל משפחה.

Credit-card importייבוא דפי אשראי

Excel and PDF statements are parsed directly; AI is used only for unknown layouts and new merchants.

דפי חיוב ב-Excel וב-PDF נקראים ישירות; AI מופעל רק על פורמטים לא מוכרים ובתי עסק חדשים.

Recurring transactionsתנועות קבועות

An engine that creates monthly, bi-monthly, weekly and bi-weekly payments automatically, backwards and forwards.

מנוע שיוצר אוטומטית תשלומים חודשיים, דו-חודשיים, שבועיים ודו-שבועיים, אחורה וקדימה.

Spending dashboardsדשבורדים של הוצאות

Monthly balance, doughnut charts by category and family member, and month-over-month comparison.

מאזן חודשי, גרפים לפי קטגוריה ובן משפחה, והשוואה בין חודשים.

Budgets and alertsתקציבים והתראות

Set budgets per category and get flagged when one is about to overrun.

מגדירים תקציב לכל קטגוריה ומקבלים התראה לפני חריגה.

Built to be trustedבנוי לאמינות

Row-level security on every table, rate limiting, and 2,117 automated tests.

הרשאות ברמת השורה בכל טבלה, הגבלת קצב בקשות ו-2,117 בדיקות אוטומטיות.

ScreensמסכיםOn desktop and phoneבמחשב ובטלפון

OutcomeתוצאהShipped and runningבאוויר ועובד

SmartFin is deployed to production on Railway and open for sign-up. I built it end to end, from database schema to the receipt-scanning pipeline.

SmartFin רץ בפרודקשן על Railway ופתוח להרשמה. בניתי אותו מקצה לקצה, ממבנה מסד הנתונים ועד תהליך סריקת הקבלות.
