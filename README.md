# Matan Shneor — Personal Website

Single-page personal portfolio site for Matan Shneor (MBA, Hebrew University of Jerusalem — Analytics & Big Data / Finance), built to support his search for a Data Analyst / Business Intelligence role.

**Live site:** https://matanshneor.github.io/Matan-Website/ (hosted via GitHub Pages, served from `main`)

The site covers: About, Professional Experience, Education, Featured Projects, Skills, and Contact.

## Stack

Plain HTML/CSS/JS — a single self-contained `index.html` file, no build step or dependencies. Fonts are loaded from Google Fonts (Playfair Display + Inter).

## Structure

- `index.html` — the entire site (markup, styles, and scripts)
- `images/` — profile photo
- `google087909bf77012d01.html` — Google Search Console site-verification file

## Deployment

Any push to `main` updates the live site automatically via GitHub Pages — no build or deploy step needed.

## Running locally

Just open `index.html` in a browser — no server required.
